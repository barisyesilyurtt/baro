# ÇAKBOT

Tek tuşluk hurda-robot oyunu. Şerit seç, gelen şeye **ÇAK**, parçala.

```bash
python3 -m http.server 4173
```

`http://localhost:4173` — Boşluk / tık / kırmızı buton yumruk. `W` `S` veya ▲▼ şerit.

Yeni eşya için `game.js` içindeki `JUNK` dizisine bir satır ekle. Hız `BASE_SPEED`, sıklık `SPAWN_MS`.
